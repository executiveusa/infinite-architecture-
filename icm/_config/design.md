# Design Canon

`STYLE_GUIDE.md` is the visual source of truth. Apply the ADHD 5/5 gate:

1. Orientation within five seconds.
2. Relevance in the first viewport.
3. One dominant idea per major viewport.
4. One primary conversion action.
5. An obvious next step with no hidden consequence.

Use editorial biophilic mode for public pages and technical field mode for private/technical pages.
Mobile is designed deliberately, not treated as a compressed desktop layout.
